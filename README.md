# 人生闯关

一个像素小人闯关的网页小游戏。小人要穿过 8 个人生关卡，每关 5 道题，共 40 题：

- 答对：小人跳过拦路的坑，人生价值 +100（记进寿命、财富、自由三项），连续答对有加成
- 答错：生命值 −20，归零可以从本关重来
- 每通过一关：生命值 +15
- 走到终点，小人成为「人生赢家」，最后列出答错的题和原文链接

单个 `index.html`，不需要构建，直接用浏览器打开就能玩。开启 GitHub Pages 后可以在线访问。

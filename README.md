# 人生闯关 · 卡牌远征

一个直接用浏览器打开的像素风卡牌闯关游戏。三幕分别是「身体」「钱包」「红线」，目标是击败第三幕 Boss，成为「人生赢家」。游戏保留了原版小人精灵和结局里的王冠、西装、领奖台、房子与烟花。

## 玩法

1. 开局在运动达人、谨慎派、养生派、学霸四种天赋中选一种。起始生命 70，初始牌组是「说不」×5 和「系安全带」×4。
2. 每幕走六层地图：普通战斗、路线选择、精英或普通战斗、路线选择、休息点、Boss。地图中的「战／精／问／宝／休／王」分别对应战斗、精英、问答驿站、宝箱、休息点、Boss。
3. 战斗每回合抽五张牌。先答一道四选一题：答对获得 3 能量（学霸为 4），答错获得 1 能量。答题后可看解析和原文链接，再出牌。敌人的下回合意图显示在其头顶。
4. 答题后可在出第一张牌前选本回合姿态：猛攻每次攻击 +2、获得护甲 −2；坚守每次攻击 −2、获得护甲 +3；均衡没有修正。出牌后姿态锁定。攻击牌积累「攻势」（上限 5，每过一回合衰减 1），「一次停掉」和「复利」会消耗攻势打出强力收尾；「直接走开」能绕过护甲，「留证据」为下一次攻击制造破绽。单次造成至少 12 点生命伤害可打断敌人的蓄力。
5. 防御牌有不同应对方式：「系安全带」抵消首段伤害，「应急金」结转剩余护甲，「分散投资」每次被攻击都会反击，「提前预警」根据敌人是否要攻击获得额外防护或抽牌。部分敌人会打出穿甲攻击，让半数护甲失效。攻击力加在每次攻击上，防御力加在每次获得的护甲上。护甲先吸收普通伤害；易伤增加所受伤害，虚弱减少造成的伤害。玩家护甲在每个自己回合开始时清零（应急金结转除外），敌人护甲在其行动开始时清零。抽牌堆用尽时会洗入弃牌堆；消耗牌只在当前战斗移除。
6. 战后从四张随机牌中选一张，也可跳过。精英战更容易获得高稀有度牌。问答驿站答对可永久提升一项属性，答错扣 6 生命；宝箱给遗物；休息点可恢复 30% 最大生命或升级一张牌。
7. 死亡后可从本幕开头的存档重来，或重新开始。结局显示总分、答对率、总伤害、最长连对、最终牌组和答错题回顾。

键盘操作：答题按 `1`–`4`；答完后用数字键打出对应位置的手牌；`A` 猛攻、`D` 坚守、`S` 均衡、`E` 结束回合。手机上可点按全部操作。页面支持约 400px 宽度，且遵循系统的减少动态效果设置。

## 题目与来源

内置 272 道题，按三幕分池：第一幕 113 题，第二幕 85 题，第三幕 74 题。每道题有四个选项、解析，以及对应原文的 `#e-节号-条号` 链接。每局在当前幕的题池中随机不重复抽题，抽完再重新洗牌。

题目与解析改编自 [《高性价比人生指南》](https://eternity4719.github.io/HowToLiveBetter/)（[eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)），原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.zh-hans)。本游戏的解析数字沿用对应原文条目；涉及自杀与性等敏感条目未纳入题池。

## 运行与测试

游戏只有一个 `index.html`，无需构建，也不加载 Google Fonts 之外的运行时依赖。直接用浏览器打开，或把仓库配置为 GitHub Pages 即可部署。

仓库里的 `playwright-sim.cjs` 是自动对局脚本。测试时先在本地安装 Playwright 及 Chromium（仅测试工具，游戏不需要）：

```bash
npm install --no-save playwright
npx playwright install chromium
node playwright-sim.cjs
```

脚本分别以 100%、75%、50% 的答对率各自动打 20 局，优先打出当前能量允许的最高费牌，输出通关数和死亡幕数，并检查浏览器控制台错误与手机宽度横向溢出。
